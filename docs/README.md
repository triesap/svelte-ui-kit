# Documentation

svelte-ui-kit installs editable Svelte/TypeScript and plain CSS into an existing
SvelteKit application. The private local distribution has no kit runtime
dependency; the application owns its source, styles and native dependencies.

## Adopt and operate

- [Getting started](getting-started.md): exact local toolchain, authentic native
  preparation, separate packed CLI host/application and first component.
- [CLI](reference/cli.md): commands, plans, structured output and refusal/exits.
- [Configuration](reference/configuration.md): desired roots, custom mappings,
  generated layout and semantic lock ownership.
- [Components](reference/components/README.md): actual installable IDs, composition,
  authored public types and manifest-derived exports.
- [Styling](guides/styling.md): app-owned CSS, themes, radius and portal inheritance.
- [Upgrading](guides/upgrading.md): comparison/cohorts, conflicts, retained
  customization, retirement and application import review.
- [Recovery](guides/recovery.md): diagnosis, interruption safety, external backup
  and independently verified owner quarantine.
- [Compatibility](reference/compatibility.md): tested native graph, SSR/form/CSP,
  contrast, browser and filesystem limits.
- [Changelog](CHANGELOG.md): local unreleased changes, not an npm release announcement.

## Repository maintenance

Maintenance guidance is excluded from local package archives. In the
[development repository](https://github.com/triesap/svelte-ui-kit), start with
`docs/CONTRIBUTING.md` for setup/review policy, `AGENTS.md` and
`docs/agents/README.md` for task routing, `docs/agents/testing.md` for acceptance
commands, and `docs/provenance.md` for immutable historical attribution.
The shared public reference above remains the API context for humans and agents.

Machine facts live in package.json, registry/manifests, authored types, versioned
schemas and native producer inputs. Docs express guarantees and interpretation;
an implementation disagreement needs investigation, not silent contract weakening.
No new ledger, full-context dump, documentation site or parallel API database is
part of this documentation set. Local packing does not authorize publication.
